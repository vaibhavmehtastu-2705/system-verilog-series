## 👋 About This Journey

I'm Vaibhav Mehta, an Electronics and Communication Engineering student exploring SystemVerilog, RTL design, testbench development, simulation, and functional verification.

This repository documents my learning through concepts, code, practical exercises, simulation experiments, debugging, and technical documentation.

My goal is to understand how to describe digital hardware, develop effective testbenches, and verify that designs behave as expected.

## 🎯 Areas of Focus

- SystemVerilog fundamentals and data types
- Combinational and sequential RTL
- Testbench development
- Simulation and waveform analysis
- Self-checking testbenches
- Functional verification
- Assertions and verification methodologies
- Debugging and corner-case analysis
