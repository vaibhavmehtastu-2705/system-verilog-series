## ◈ The Mission

This repository documents my journey into **SystemVerilog and digital verification**.

The goal is to understand not only how hardware behaves, but also how to write testbenches, detect design errors, verify expected behavior and interpret simulation results.

Every topic will be explored through concepts, code, experiments and documented learning milestones.

**No artificial deadlines. No rushed learning. Just consistent engineering practice.**

## ⬡ The Learning Console

| Track | What I am exploring |
|---|---|
| `01 / FUNDAMENTALS` | Data types, operators, vectors and language constructs |
| `02 / RTL DESIGN` | Combinational logic, sequential logic and synthesizable RTL |
| `03 / TESTBENCH` | Stimulus generation, checking outputs and reusable test code |
| `04 / SIMULATION` | Compiling, running simulations and analysing waveforms |
| `05 / VERIFICATION` | Self-checking tests, corner cases and functional correctness |
| `06 / ASSERTIONS` | SystemVerilog assertions and temporal properties |
| `07 / ADVANCED` | Tasks, functions, interfaces, constrained randomization and coverage |

*These are learning tracks, not completed achievements. Each will be explored when its prerequisites are understood.*

## 📈 Progress Philosophy

This is a self-paced journey, not a fixed-duration challenge.

- Learn a concept before moving forward.
- Write and understand the code myself.
- Test behavior instead of assuming correctness.
- Investigate failures and unexpected waveforms.
- Document meaningful progress.
- Commit changes when a useful milestone is complete.

A topic may span several sessions and commits. Learning speed is flexible; engineering discipline is not.
